# 작업 재개·스킬·외부 도구

## 보존된 작업 이어가기

1. **작업 초안**에서 작업을 다시 열거나 **프로젝트 관리 → Git에 보존된 체크포인트 → 새 작업 공간으로 복원**을 누릅니다.
2. 요소의 AI 대화 또는 수동 작업의 **AI 실행** 안에서 **이어갈 작업**을 엽니다. 보존 기준, 이전 실행의 결과, 결정·미해결 질문·다음 행동을 확인합니다. **재개 메모 보존**으로 수정 사항을 체크포인트에 저장합니다.
3. 실행기를 선택하고 이어서 할 일을 입력합니다. 통합 대상의 채택 입력이 달라졌다면 변경 목록을 검토한 뒤 보존된 기준에서 계속할지 결정합니다. 현재 기준을 쓰려면 새 작업을 시작합니다.

CRAFT는 Git 작업 브랜치에서 초안·변경안·검토·체크포인트·기록된 요청을 복원합니다. 실행기를 바꿀 때 보존 자료로 새 세션을 시작합니다. 다른 복제본에서 복원하려면 작업 브랜치도 가져와야 합니다. 중단된 승인 요청은 새 실행에서 다시 확인합니다.

## 스킬 사용

기본 스킬은 `project-resume`, `design-document`, `scene-writing`, `change-impact`, `consistency-review`입니다. **이어갈 작업 → 이번 실행에 사용할 스킬**에서 **보존된 스킬 선택 사용**을 끄고 최대 다섯 개를 고릅니다. 목록에서 내용, 출처, 버전, 해시를 확인할 수 있습니다.

프로젝트 스킬은 프로젝트의 `skills/<id>/`에, 개인 스킬은 CRAFT 앱 데이터의 `skills/<id>/`에 둡니다. 각 디렉터리에 `SKILL.md`와 `skill.yaml`을 만들고 매니페스트에 `id`, `version`, `entrypoint: SKILL.md`를 작성합니다. 공급자 전용 스킬도 사용할 텍스트를 이 형식으로 준비할 수 있습니다. [기본 매니페스트 예시](../packages/skills/scene-writing/skill.yaml).

스킬을 선택하면 Codex 또는 Claude에 텍스트 지시가 전달됩니다. 선택한 개인 스킬도 원문 사본·버전·해시가 Git 작업 브랜치에 저장되므로 새 앱에서 같은 지시로 재개할 수 있습니다.

## 외부 MCP 연결

1. **이어갈 작업 → 외부 MCP 연결 등록**에 Streamable HTTP 주소를 입력합니다. HTTPS와 로컬 테스트용 루프백 HTTP를 지원합니다.
2. 허용 도구를 `read:tool_name` 또는 `write:tool_name` 형식으로 한 줄씩 등록합니다. Bearer 인증을 쓴다면 로컬 앱 실행 환경에 `CRAFT_MCP_SECRET_EXAMPLE` 같은 변수를 설정하고, 화면에는 `env:CRAFT_MCP_SECRET_EXAMPLE` 같은 참조만 넣습니다.
3. 실행마다 사용할 연결을 선택합니다. 서버 연결과 인증은 도구를 요청할 때 확인합니다. 외부 쓰기가 요청되면 대상과 요청 내용을 확인한 후 승인합니다.

CRAFT는 보내기 전에 작업 기록을 보존하고 동일한 요청을 받으면 기존 기록을 반환합니다. 응답에서 `structuredContent.jobId`가 오면 외부 작업 ID를 남깁니다. 선택 항목인 외부 작업 상태 조회 도구는 읽기로 허용되어야 합니다. 조회 도구에 `{ jobId }`를 전달하며 `structuredContent.status` 값이 `pending`, `completed`, `failed`이면 체크포인트를 갱신합니다.

응답이 끊기면 **외부 결과 확인 필요**로 표시합니다. 실제 서비스에서 부작용 여부를 확인할 수 있습니다. 중복 방지는 CRAFT 관리 경로와 작업 기록을 공유하는 Git 저장소 범위에서 동작합니다. 직접 shell/API 호출과 작업 기록을 교환하지 않은 복제본에는 별도 서버 측 멱등성이 필요합니다.

## PNG 첨부

**직접 편집 → 이미지 첨부**에서 정적 PNG와 대체 텍스트를 입력합니다. 지원 범위는 가로·세로 최대 2,048px, 파일당 256 KiB입니다. 파일이 해시 기반 경로에 저장되고 링크가 초안에 추가됩니다. 새 리비전 본문에 링크를 유지하면 검토 화면에서 이미지를 확인할 수 있고 승인 통합에 파일도 포함됩니다. 이미지 생성 공급자와 시퀀스 그래프는 별도 검토를 따릅니다. [이미지 생성·문서 시각화 검토안](VISUAL_TOOLS_PROPOSAL.md).

에이전트는 `changes.propose`의 `images`에 작업 시작 시점에 존재한 PNG의 프로젝트 상대 경로(`sourcePath`)와 대체 텍스트(`alt`)를 넘깁니다. 가로·세로 최대 2,048px, 파일당 8 MiB의 정적 PNG를 지원합니다. CRAFT가 원본 바이트를 해시 경로로 복사하고 제안 리비전과 작업 미리보기에 같은 링크를 기록합니다. 같은 PNG를 여러 문서에 연결하면 해시 경로를 공유합니다.

통합 검토에는 바이너리 파일의 경로와 Git 객체 해시가 diff에 표시되며, 이미지 자체는 미리보기에서 확인할 수 있습니다.
