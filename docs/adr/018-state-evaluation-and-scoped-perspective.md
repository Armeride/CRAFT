# ADR-018 · 파생 상태 평가와 관점 제한

- 날짜: 2026-11-19
- 상태: 채택
- 기준: [명세 8절](../PROJECT_SPEC.md#8-분야별-확장-모델), [작업 008](../tasks/008-domain-queries.md)

## 결정

- 색인 worker가 캡처한 한 파일 집합과 기준에 두 비교를 실행한다. 정본은 Git 파일에 둔다. 평가 입력에는 snapshot·scope·기준/스키마·시점·사건·관측할 개체·가정과 의미 digest를 포함한다. 로컬 결과의 분리 키는 등록과 작업 범위를 포함한다.
- 평가기는 `state-evaluator-1`로 기록하고 파일 reader pin과 공개 core·확장 v1은 유지한다. 초기값 시점, 선언적 비교와 효과, 3값 논리, 개체별 상태, 동일 순서의 원자적 충돌과 유한 연쇄를 계산한다. 정본 기록은 명시된 발생으로만 재생하고, 가정의 효과는 사용자가 조회한 상태에서만 계산한다.
- 장면에는 선택 리비전과 명시한 세계 시간을 핀으로 고정한다. 독자 공개는 별도로 원고 순서의 경계를 사용한다. 모호한 순서·시간 누락·근거 핀의 변경은 진단한다. 채택 규칙, 미채택 후속, 기록된 빌드 관찰을 각각 조회하고 같은 단위·정확 핀으로 차이를 계산한다.
- 인물·독자 조회는 공개 표현으로 별도의 검색·정확 조회 결과를 만들고 조회 안에서만 유효한 식별자를 반환한다. 근거 파일·원본 제목·연결 확장·작업 본문은 작가 보기에서 사용한다. 독자 공개 표현은 reveal의 명시 문장, 인물 표현은 인식 사건에 작성한 본문이다.
- 관점 제한 AI는 확정 자료의 신규 Claude 작업에 제공한다. 프로젝트 밖 임시 폴더, 공급자 설정 로딩 제한, 파일·셸 도구와 승인 차단, 고정 기준 전용 MCP로 구성한다. 운영체제 실행 파일 격리와 실제 계정 모델 시험은 별도 검증 범위다. 일반 실행의 기존 작업 편집 기능을 유지한다.

## 검증

[작업 008 결과](../tasks/008-domain-queries.md)에서 시점·동시성·가정·공개·브라우저 인수 증거를 확인할 수 있다.
