# ADR-014 — 교체 가능한 관계 그래프와 탐색 캔버스

상태: UI 초안 03에 채택, 2026-11-13. 외부 라이브러리 채택은 보류.

사용자는 외부 오픈소스는 우선 검토하고, 엔진 확장/설정 전환과 연결이 많은 요소 중심의 펼쳐지는 군집·확대/축소 가능한 캔버스를 요청했다. [후보 검토와 계약](../GRAPH_ENGINES.md)에 확정 요구·설계 판단·후순위를 기록한다. FR-026, AT-67/68로 추적한다.

데이터 모델/엔진 registry/내장 배치/viewport를 분리한다. registry에는 실제 구현만 등록하고 사용자는 관계 중심/열 배치를 전환할 수 있다. 외부 adapter는 renderer 자체를 교체할 수 있으며 공통 pinned model·텍스트 목록과 exact 선택을 유지한다. 설정 값 추가는 기존 로컬 preferences v1의 호환 가능한 선택 필드이며 프로젝트 schema v1 변경이 아니다.

연결 중심의 초기 의미는 표시된 필터/한도 내 고유 이웃 수다. 입/출 방향과 병렬 참조 수는 레이아웃에서만 합치고 원래 관계/화살표는 유지한다. 중심 고정·유한 force 휴리스틱과 양의 modularity 병합을 사용한다. 군집은 시각적 제안이며 의미 분류나 최신 리비전 치환이 아니다. 불완전/잘린 범위를 표시하고 모든 노드의 최적 배치나 전체 그래프 중심성을 보장하지 않는다.

캔버스는 우선 SVG/HTML viewport로 구현해 현재의 버튼/키보드/번역·테마를 재사용한다. pan·zoom·fit과 별도 관계 목록을 제공하며 물리 시뮬레이션은 유한 계산 후 정지해 지속 애니메이션을 강요하지 않는다. 일반 wheel은 페이지 스크롤, Ctrl/Cmd+wheel은 그래프 확대다. 외부 엔진 후보는 설치하거나 설정에 미리 노출하지 않는다.

고급 force/worker·실측 대형 성능·확장 라이선스 검증·범용 GPU fallback은 외부 도입 시 수행한다. 사용자 노드 고정·위치 저장/내보내기·터치 pinch 등은 독립 확장이다. ADR-013의 고급 graph 후순위 중 엔진 선택/관계 배치/확대·이동만 이번 사용자 요청으로 앞당겼다. 단계 5 전체 완료나 단계 6 착수로 해석하지 않는다.
