# 개발 작업 기록

사용자가 승인한 UI 초안 03을 단계 5 기준선으로 유지한다. 단계 5 잔여 기능은 [005 수동 작업 흐름](005-manual-workflow.md)에서 완성한다.

이후 새 UI 변경 요구는 새로운 `NNN-이름.md` 작업을 만든다. 사용자 요청·목표/범위·확정 요구/설계 판단/미결정·영향·인수 기준·결과를 기록하고 해당 작업 단위로 진행한다. 완료한 단계 5를 계속 ‘초안 검토 대기’로 되돌리지 않는다. 단계 진행 지시와 독립 UI 작업을 구분하고 한 단계 완료 후 대기한다.

그래프 외부 엔진은 [후보 검토](../GRAPH_ENGINES.md)만 유지한다. 설치/교체 요청이 생기면 별도 작업에서 호환성·성능·접근성·지원 환경을 검증한다.
