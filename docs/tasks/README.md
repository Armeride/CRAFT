# 개발 작업 기록

사용자가 승인한 UI 초안 03을 기준으로 [005 수동 작업 흐름](005-manual-workflow.md)을 완료했다. 다음 세션의 진입 순서는 [시작 문서](../START_HERE.md#8-다른-세션에서-이어갈-때)를 따른다.

이후 새 UI 변경 요구는 새로운 `NNN-이름.md` 작업을 만든다. 사용자 요청·목표/범위·확정 요구/설계 판단/미결정·영향·인수 기준·결과를 기록하고 해당 작업 단위로 진행한다. 완료한 단계 5를 계속 ‘초안 검토 대기’로 되돌리지 않는다. 단계 진행 지시와 독립 UI 작업을 구분하고 한 단계 완료 후 대기한다.

그래프 외부 엔진은 [후보 검토](../GRAPH_ENGINES.md)만 유지한다. 설치/교체 요청이 생기면 별도 작업에서 호환성·성능·접근성·지원 환경을 검증한다.

[006 에이전트 실행기·내부 MCP](006-agent-runners.md)는 사용자 opt-in 후 두 공급자의 실제 시험과 회귀까지 완료했다.

[008 소설·게임 조회와 상태 평가](008-domain-queries.md)는 장면 경계, 개체별 상태 비교, 관점 제한과 게임 관찰을 다룬다.

[007 재개·스킬·외부 MCP](007-resume-skills-mcp.md)는 체크포인트 재개, 실행기 교체, 선택한 외부 작업과 PNG 첨부 보존을 다룬다.
