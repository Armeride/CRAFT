# 작업 008 · 소설·게임 조회와 상태 평가

- 상태: 완료
- 기준일: 2026-11-19
- 근거: [명세](../PROJECT_SPEC.md) 8·18절, [ADR-018](../adr/018-state-evaluation-and-scoped-perspective.md)
- 사용 방법과 예시: [시점·상태·관점 조회](../DOMAIN_WORKFLOW.md)

## 범위

- 일반 요소의 초기 상태, 트리거·조건·효과, 선택된 정본과 계획, 가정 및 대상 개체별 전후 비교.
- 장면 경계와 원고 순서, 작중 시간, 인물의 인식과 독자 공개의 독립 조회. 공개된 문장만 노출하는 제한 검색·MCP, 확정 자료 전용 Claude 프로필.
- 기준과 플랫폼·모드에서의 기획 수치·미채택 리비전·구현 관찰·결정과 근거. 기존 속성·본문·참조 비교를 이용한다.
- 한국어·영어 화면과 세 가지 미리보기 예시. 공개 core·narrative·game_design·state_model v1 스키마와 이전 fixture는 유지한다.
- 시각화는 장면 순서 전환과 사건·조건 흐름에 적용했다. 시각화 렌더러 추가 및 이미지 공급자 연결은 [후속 기획](../VISUAL_TOOLS_PROPOSAL.md)을 따른다.

## 인수 증거

- 최종 `npm run check`의 스키마 생성 검증, 타입 검사, 서버·웹 빌드 및 Vitest 27파일 218개를 통과했다. 마지막 관점 응답 제어 수정 후 타입 검사·서버/웹 재빌드·도메인 Chrome 3개를 다시 통과했다.

- 1장·5장의 국경·소유권과 조약 근거, 검토가 있는 정본과 계획·초안, 초기값 이전 미기록을 분리했다.
- 개체별 참·거짓·불명·사건 부재, 동시 충돌의 원자적 거부, 진입과 순환 한도, 입력 digest와 재구축, 정본 무변경을 확인했다.
- 회상에서 작중 시간과 읽는 순서를 구분하고, 사실·인식·공개를 분리했다. 숨은 원문·제목·참조를 검색과 MCP로 회수할 수 없는지, 제한 프로필의 작업 폴더와 파일 도구가 차단되는지 로컬 어댑터로 검증했다.
- 게임 기획과 빌드 관찰의 수치와 단위, PvE 범위 및 해당 기준의 미채택 후속을 확인했다.
- Chrome 18개 시나리오를 검증했다. 좁은 화면의 클릭 회귀를 수정한 뒤 모바일 탐색·라이트/다크 접근성·새 도메인 시나리오 총 5개를 다시 통과했다. 로컬 예시의 확정 1장/5장 비교와, 관점을 변경한 뒤 도착한 이전 작가 조회 응답이 화면에 나타나지 않는 동작도 확인했다.
