# 작업 007 · 작업 재개, 기본 스킬 및 외부 도구

- 상태: 완료
- 기준일: 2026-11-19
- 근거: [명세 9.3·11.5·12.5~6·18절](../PROJECT_SPEC.md), [ADR-017](../adr/017-portable-continuation-and-managed-tools.md)
- 사용법: [작업 재개·스킬·외부 연결·PNG 첨부](../RESUME_AND_TOOLS.md)

## 확정 요구와 설계

- 목표·고정 기준·결정·미해결 질문·다음 행동·초안과 검토가 Git에서 복원된다. 현재 통합 대상의 기준 입력이 달라지면 확인을 받는다. Codex와 Claude 연결을 바꿔 새 세션을 구성하며 승인 요청은 해당 실행에 귀속된다.
- 출처가 구분된 기본·프로젝트·개인 스킬은 명시적으로 선택한 원문과 버전·해시를 보존한다. 두 공급자는 공통 원본의 텍스트 지시를 받는다. 공개 core·확장 v1 계약 및 기존 fixture는 유지한다.
- 외부 MCP는 로컬 프로필 등록과 실행별 허용 목록을 적용한다. 쓰기 승인 및 요청 전 증거, 멱등 키, 외부 작업 ID와 확인된 상태를 체크포인트로 보존한다. 연결 세부는 [ADR-017](../adr/017-portable-continuation-and-managed-tools.md)을 따른다.
- PNG 첨부는 원문 링크와 함께 보존된다. 해시로 고정한 정적 PNG를 복원하고 승인된 문서와 통합한다. 이미지 생성 공급자와 시퀀스 그래프는 [후속 기획](../VISUAL_TOOLS_PROPOSAL.md)에 남긴다.

## 인수 증거

- 전체 `npm run check`에서 생성 스키마·타입 검사·서버/웹 빌드와 Vitest 23파일 208개가 통과했다. Chrome E2E 기존 14개와 재개·PNG 신규 시험 1개도 통과했다.

- 로컬 Codex·Claude 어댑터로 신규 앱 데이터에서 이전 결과, 메모, 개인·기본 스킬 원문과 외부 작업을 복원했다. 실행기의 공급자 세션 ID와 로컬 로그에 의존하지 않는다.
- 루프백 MCP 서버로 외부 쓰기 전 승인, job ID와 상태 갱신, 응답 중단 후 불명 표시, 다른 실행기로 재개 후 재제출 방지, 허용 목록 거부를 확인했다.
- PNG의 CRC·저장 충돌 검사, 초안 공백 보존, 작업 브랜치 복원, 검토·통합의 최종 바이트와 채택 입력 변경 표시를 확인했다.
- Chrome에서 재개 메모와 PNG가 브라우저 새로고침 후 같은 작업에 표시됐다. 기존 수동 편집·AI 제어·검토의 Chrome 시험도 통과했다.
- 실제 공급자 모델 및 실제 외부 서비스의 호출은 이번 검증 범위 밖이다. [단계 6의 실제 모델 시험](006-agent-runners.md)을 참고한다.
