# CRAFT

CRAFT는 소설과 게임의 설정, 이야기, 규칙을 한곳에서 관리하는 로컬 우선 웹 앱입니다. 인물이나 지역, 게임 규칙을 요소로 기록하고, 리비전별 변경 내용과 요소 사이의 관계를 살펴볼 수 있습니다. 프로젝트 원본과 작업 기록은 로컬 Git 저장소의 파일에 보관합니다.

- **탐색** · 전체 및 분류별 대시보드, 본문 검색, 관계 그래프, 리비전 비교로 필요한 자료를 찾습니다.
- **편집과 검토** · 별도 작업 공간에서 초안을 작성하고, 변경 내용과 영향을 검토한 뒤 프로젝트에 반영합니다.
- **AI 작업** · 요소별 대화에서 설치된 Codex 또는 Claude에 작업을 요청하고, 옆 문서에서 변경안을 확인합니다.
- **화면 설정** · 한국어와 영어, 라이트와 다크 모드, 글꼴과 패널 배치를 선택할 수 있습니다.

## 시작하기

Windows x64에서 Git, Node.js **24.21.0**, npm **11.19.0**을 준비합니다. CRAFT 소스 폴더에서 다음을 실행합니다.

```powershell
npm ci
npm run ui:preview
```

브라우저에서 [http://127.0.0.1:4173](http://127.0.0.1:4173)을 엽니다. 처음 실행하면 바로 둘러볼 수 있는 예시 프로젝트가 생성됩니다. 예시와 앱 데이터의 기본 위치는 `.tmp/ui-preview`입니다. 서버를 종료한 뒤 다시 실행하면 같은 작업을 열 수 있습니다.

## 프로젝트에서 작업하기

1. **프로젝트 열기**에서 `project.yaml`이 있는 CRAFT 프로젝트의 Git 저장소 폴더를 입력합니다. Git에 저장된 기존 Markdown이나 텍스트 파일은 **프로젝트 관리**에서 가져올 수 있습니다.
2. 왼쪽 메뉴에서 분류나 요소를 선택합니다. 대시보드의 관계 그래프에서 연결을 탐색하고, 요소 화면에서 본문·참조·리비전을 확인합니다.
3. **직접 편집**을 열어 작업 초안을 작성합니다. 저장한 초안은 **작업 초안**에서 다시 열 수 있습니다.
4. 새 리비전을 만들거나 AI가 제안한 초안을 검토합니다. 프로젝트에 반영하려면 **통합 diff 준비**에서 실제 변경 내용을 확인하고 승인합니다.

### AI와 함께 편집하기

요소에서 **AI 대화 열기**를 누르고 실행기를 선택한 뒤 지시를 입력합니다. Codex 또는 Claude를 사용하려면 해당 실행기를 설치하고 로그인해야 합니다. 실제 AI 실행에는 서비스 사용량이 발생할 수 있습니다. **로컬 테스트 실행기**를 선택하면 모델 호출 없이 질문, 승인, 초안 생성 흐름을 체험할 수 있습니다.
